# PDF개인정보삭제기 (PDFprivacyedit)

고등학교 입학 지원서(생활기록부 등) PDF에서 개인정보를 찾아 검은 박스로 덮고,
밑의 텍스트·이미지 데이터까지 완전히 지운 뒤 새 PDF로 저장합니다. 전부 로컬에서만 동작합니다.

## 파일
- app_web.py + ui/index.html : 메인 앱 화면 (pywebview)
- app.py     : 예비용 단순 화면 (Tkinter)
- engine.py  : 탐지·삭제 엔진
- ocr.py     : 스캔 PDF용 OCR (Tesseract)
- batch.py   : 터미널용 일괄 처리
- .github/workflows/build.yml : GitHub에 올리면 윈도우 exe / 맥 app 자동 빌드

## exe / 맥 앱 받기 (GitHub Actions)
1. 이 폴더를 GitHub 저장소(main 브랜치)에 push
2. 빌드가 끝나면 저장소 → Releases 에 "빌드 #번호"로 올라옵니다 (Actions 탭 Artifacts 에도 3일간 보관)
   - PDFprivacyedit-windows.exe : 윈도우용 exe 하나 (Tesseract 한국어 OCR 포함, 설치 불필요). Release 는 한글 파일명을 못 써서 영문 이름이며, 받은 뒤 이름을 바꿔도 됩니다
   - PDFprivacyedit-mac.zip : 맥용 .app (OCR은 `brew install tesseract tesseract-lang` 필요)
   - main 이 아닌 브랜치에서 수동 실행한 빌드는 "Pre-release"로 표시됩니다
3. 윈도우 첫 실행 시 SmartScreen 경고 → "추가 정보" → "실행". 맥은 우클릭 → 열기.
4. "스마트 앱 컨트롤이 … 차단했습니다"라며 아예 실행이 안 되는 PC(윈도우 11 새 PC에 기본 켜짐)는
   "추가 정보" 우회가 없습니다. 설정 → 개인 정보 및 보안 → Windows 보안 → 앱 및 브라우저 컨트롤 →
   스마트 앱 컨트롤 설정 → "끄기"로 바꾼 뒤 실행하세요. (한 번 끄면 윈도우를 다시 설치하기 전엔 다시 켤 수 없습니다.
   코드 서명 인증서로 exe에 서명하면 끄지 않아도 되는데, 이건 유료라 아직 적용하지 않았습니다.)

## 파이썬으로 바로 실행 (테스트용)
윈도우: run_windows.bat 더블클릭   /   맥: run_mac.command 더블클릭 (Python 3.10+ 필요)

## 삭제 항목
성명 / 주민등록번호 / 생년월일 / 전화번호 / 이메일 / 주소 / 사진 / 학적사항(입학·졸업 학교) / 반·번호 / 대장번호 / 학교명 / 출력정보(IP·출력자)
- 기본으로 켜지는 항목: 성명, 주민등록번호, 생년월일, 전화번호, 이메일, 주소, 사진, 학적사항, 반·번호, 출력정보
- 반·번호는 첫 장 표의 반/번호 열과 본문 속 "1-5", "2학년 5반" 같은 학년-반 표기를 함께 지웁니다.
전체 기본값을 정한 뒤, 파일 목록에서 파일을 클릭해 개별로 바꿀 수 있습니다(★ 표시).
저장 폴더의 _report.json 에 파일별로 무엇을 어디서 지웠는지 기록됩니다.

## 파일 넣기 / 저장 파일명
- "폴더 선택"은 그 폴더 바로 안의 PDF만 넣습니다(하위 폴더는 보지 않음). 이미 목록에 있던 파일은 비우고 그 폴더의 PDF로 바꿉니다.
- 파일을 끌어다 놓거나 클릭해서 고르면 목록에 추가됩니다. 목록의 각 줄에 파일이 있는 폴더가 회색으로 표시됩니다.
- 저장 파일명 규칙: `{이름}` = 원본 파일 이름, `{번호}` = 목록 순번(001, 002, …). 기본값은 `{이름}_삭제본`.
  예) `지원자{번호}` → 지원자001.pdf, 지원자002.pdf … (원본이 어느 파일인지는 _report.json 에 남습니다)
